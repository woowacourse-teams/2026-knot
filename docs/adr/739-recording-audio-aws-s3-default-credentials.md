# 녹음 오디오 저장소는 AWS S3 전용으로 구성하고 AWS SDK 기본 자격 증명 체인을 사용한다

## 상태

Proposed

## 관련 Issue

- #739 [BE] S3 업로드 설정과 DB 처리 최소화

## 한 줄 요약

녹음 오디오 저장소는 AWS S3 전용으로 구성하고 AWS SDK 기본 자격 증명 체인을 사용한다

## 왜 이 결정이 필요했나

도메인 책임 이동 이후 필요한 최소 코드만 남기는 후속 S3 업로드 리팩토링이다. 과거 ADR 482의 공급자 교체 가능성 동인은 호환 endpoint·앱 전용 고정 키 설정으로 구현돼 있었다.

실제 설정에 NCP 등 S3 호환 endpoint와 고정 키·path-style 지원이 남아 있어 제거 범위를 사용자에게 확인했고, 사용자가 AWS 전용·EC2 역할·기본 체인을 선택했다.

결정 동인:

- 실제 사용하는 AWS S3 범위에 맞춰 설정·분기 최소화
- 기본 자격 증명 체인에서 EC2 역할 임시 자격 증명 사용 가능
- 업로드·버전 고정·삭제·권한 재검증 계약 보존

## 트레이드 오프

- 기존 호환 저장소·앱 전용 고정 키 설정 유지: 공급자를 설정으로 바꿀 수 있지만 endpoint·자격 증명·path-style 분기를 계속 관리한다
- AWS S3 전용·SDK 기본 체인 사용(채택): 중복 builder·앱 전용 인증 설정을 제거하고 호환 저장소 전환은 다시 코드 검토한다

## 무엇을 결정했나

녹음 오디오 저장소는 AWS S3 전용으로 구성하고 AWS SDK 기본 자격 증명 체인을 사용한다

사용자의 코드 최소화 목표와 AWS 전용 선택을 적용한다. 인증·endpoint 선택은 SDK 기본 기능을 사용하고 업무 검증과 외부 I/O 경계는 유지한다.

## 결과

- 앱 설정에는 region·bucket·keyPrefix·URL TTL만 남긴다
- 앱 전용 endpoint·access key·secret key와 path-style 강제 설정은 제거한다
- 기본 체인은 환경·시스템 속성·프로필 등이 EC2 역할보다 우선할 수 있으며 역할 전용 강제가 아니다
- AWS 표준 endpoint override 기능은 남는다
- 기존 region·bucket·prefix·버전 고정·전체 버전 삭제·5초 timeout을 유지한다
- 이 결정은 ADR 482의 공급자 설정 교체 동인만 대체하고 FE 직접 업로드 방식은 유지한다
- 로컬 합성 자격 증명·stub 테스트와 실제 버킷 권한·운영 검증은 구분한다

## 다시 논의해야 할 조건

- AWS 이외 S3 호환 저장소를 실제 지원해야 할 때
- SDK 기본 체인으로 해결할 수 없는 자격 증명 출처나 endpoint 정책이 확정될 때
