첫 섹션은 반드시 아래 형식이다. 중괄호는 작성 지시이며 결과에 복사하지 않는다.

## 핵심 요약
{지정 주제의 맥락·최종 합의·조건·남은 쟁점을 읽기 쉽게 설명한다.}

그 다음은 실제 항목이 있는 섹션만 아래 순서로 둔다.
## 결정
## 보류
## 미결정
## 할 일

내용이 없는 섹션은 heading까지 생략한다. "없음", "해당 없음", 빈 목록을 쓰지 않는다.
각 항목은 원문의 사실과 조건을 보존한다. 보류 항목 끝에는 회의에서 말한 실행 조건·시점을 붙인다.
고정 섹션 뒤에는 회의 내용에 맞는 추가 H2 heading(배경, 이유, 우려, 대안, 제안 등)을 직접 골라 이어 쓴다.
H1 문서 제목은 content에 넣지 않는다. title은 별도 JSON 필드다. 안내 문장이나 템플릿 경로도 결과에 넣지 않는다.

마지막으로 확인한다. 실행하기로 합의했어도 실행 시점에 조건이 있다면 그 실행은 결정이 아니라 보류에 한 번만 쓴다.
예를 들어 "유료 고객이 800명을 넘으면 개발하고 그 전에는 하지 않는다"는 보류다. 결정 섹션에 다시 쓰지 않는다.
실행할지 아직 정하지 않았다면 보류가 아니라 미결정이다.
