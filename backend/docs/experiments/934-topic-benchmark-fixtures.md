# #934 성능·분류 품질 비교용 합성 자료

2026-10-23. 실제 팀 회의 원문이 아닌 실험용 합성 사례 50개다. 테스트 설계 시 기대 배정을 고정했으며 팀원이 검토한 정답 자료는 아니다. 일반 정확도나 운영 품질을 대표하지 않는다. 같은 사례를 제목의 검토 번호만 달리해 100개·1,000개로 늘렸으며 의미적으로 독립적인 회의 1,000개를 뜻하지 않는다.

## 자료 구성과 평가

기존 후보는 녹음·전사(e:1), 문서 생성(e:2), 워크스페이스·권한(e:3), 검색·탐색(e:4), 배포·운영(e:5), 데이터·저장소(e:6), 알림(e:7), 사용자 경험(e:8)이다. 철학 독서와 채용은 별도 새 주제가 필요하며 둘을 기존 영역이나 서로 합치면 오분류다.

각 영역 5개 중 마지막 사례는 제목·요약만으로 잘못 판단할 수 있고 본문 근거에 실제 논의 대상이 있다. 초대 사례에는 자료 안의 지시문을 무시하는지도 포함한다. 예상 배정은 성능 실험 전에 고정했다. 일부 영역 경계(검색의 사용성, DB 복원과 운영 등)는 실제 팀의 추가 검토가 필요하므로 아래 기대값 기준의 오차로 표현한다.

short는 아래 본문 근거 전체, long은 같은 근거와 일반 문장을 반복해 최대 2,000자로 늘린 입력이다. long은 토큰·메모리 부하를 위한 자료로 정보 밀도 높은 실제 장문을 재현하지 않는다. ID 1부터 사례 순서대로 부여하고 전체 문서를 seed=934로 섞어 배치를 구성한다. 반복 비교에서는 ID·문서·후보·기대값을 고정한다. 매 배치의 새 후보를 충돌하지 않는 key로 변환한 뒤 마지막 CONSOLIDATE 호출로 통합한다. 이 실험용 조합은 현재 Java 실행 경로와 구분한다.

평가 항목은 정확한 ID 커버리지·중복·없는 후보 참조, 기존 후보 재사용, 새 영역의 기존 영역 오배정, 서로 다른 영역의 잘못된 통합, 같은 영역의 불필요한 분리, 반복 실행의 최종 배정 일치다. 비율은 문서별 또는 문서 쌍별 분모를 표시한다. 소수 실험으로 p95나 운영 SLA를 주장하지 않는다.
