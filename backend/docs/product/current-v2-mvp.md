# 현재 제품 요구사항 확인

제품 기획·기능 요구사항·도메인 규칙·API 명세·QA 시트는 Notion, UI는 Figma가 정본이다.
원문 위치는 [하네스 정본 목록](../../../.agents/skills/knot-feature/references/sources.md)을 따른다.
이 파일에는 제품 정책 사본이나 과거 대화의 결정을 누적하지 않는다.

1. 요청이나 Issue의 관련 원문 링크를 읽고 현재 적용 범위와 문서 상태를 확인한다.
2. 백엔드 근거 탐색은 [Notion 근거 확인](../notion-context.md)을 따른다.
3. 관련 Issue·ADR·코드·테스트와 대조해 요구사항과 현재 구현을 구분한다.
4. 충돌은 [정합성 기준](../../../docs/harness/notion-alignment.md)에 따라 처리한다.

기획서는 읽기 전용이다. 제품 기획 기준 변경은 유월의 승인이 필요하다.
정본에 접근할 수 없으면 해당 근거가 필요한 단계는 `blocked`로 보고한다.
과거 요약이나 로컬 사본만으로 최신 요구사항을 확정하지 않는다.
