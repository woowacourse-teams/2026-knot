# 녹음 연결 끊김 유예를 마지막 생존 뒤 30분(설정값)으로 늘려 만료 끝난 시각을 마지막 생존 시각으로 하고, 같은 탭 새로고침 복구는 별도 이어 받기 API에서 녹음 탭 증명을 새 값으로 바꿔 한다

## 상태

Proposed

## 관련 Issue

- #1065 [BE] 녹음 연결 끊김 30분 유예와 같은 탭 새로고침 뒤 이어 받기

## 한 줄 요약

녹음 연결 끊김 유예를 마지막 생존 뒤 30분(설정값)으로 늘려 만료 끝난 시각을 마지막 생존 시각으로 하고, 같은 탭 새로고침 복구는 별도 이어 받기 API에서 녹음 탭 증명을 새 값으로 바꿔 한다

## 왜 이 결정이 필요했나

ADR 695는 탭을 닫은 녹음을 빨리 끝내려고 10초 신호·30초 만료를 정했다. 그 뒤 운영에서 일시 장애·재배포·화면 꺼짐으로 녹음이 끝나는 사례가 매일 생겼다. 30분 유예로 같은 탭 새로고침 뒤 이어서 녹음(STT-R26)을 열면서 ADR 378의 시작 재요청 복구와 sessionStorage 증명 복제 문제도 함께 정해야 했다

운영 DB 최근 14일 CONNECTION_EXPIRED 29건, 녹음이 있던 날마다 발생했고 회원 10명 이상이 겪었다. 신호가 30초만 끊겨도 녹음이 끝나고 녹음 탭은 올리지 못한 소리를 버린다.

결정 동인:

- 일시 장애·화면 꺼짐에도 녹음과 소리를 잃지 않기
- 두고 온 녹음이 새 녹음을 오래 막지 않기
- 일시정지 녹음의 유일한 자동 종료 유지
- 복제 탭 중 먼저 이어 받은 하나만 녹음 탭
- 시작 API의 새 녹음 생성 경로와 복구 경로 분리

## 트레이드 오프

- 현재 유지(ADR 695, 10초 신호·30초 만료): 닫은 탭의 녹음이 30초 안에 끝나지만 짧은 끊김에도 녹음이 끝나고 남은 소리를 버린다
- 마지막 생존 뒤 30분 유예(채택, 요청자 결정·기획 컨펌 2026-10-27): 짧은 끊김을 견디지만 닫은 탭의 녹음이 최대 30분 진행 중으로 남아 새 녹음을 막고 끊긴 시간이 녹음 시간에 들어간다
- 시작 재요청(ADR 378, 요청 원문의 4단계 안): 같은 requestId·tabId·controlToken으로 같은 세션을 돌려받는다. 증명을 바꾸지 않아 복제 탭이 함께 제어할 수 있고, 끝난 녹음의 endReason을 주려면 시작 응답을 넓혀야 한다
- 별도 이어 받기 API와 증명 교체(채택, API 명세 2026-10-27): recordingId로 대상을 정하고 먼저 접수된 한 탭만 새 증명으로 바꾼다. API가 하나 늘고 이전 증명 요청을 모두 403으로 거절해야 한다

## 무엇을 결정했나

녹음 연결 끊김 유예를 마지막 생존 뒤 30분(설정값)으로 늘려 만료 끝난 시각을 마지막 생존 시각으로 하고, 같은 탭 새로고침 복구는 별도 이어 받기 API에서 녹음 탭 증명을 새 값으로 바꿔 한다

짧은 장애·화면 꺼짐은 대부분 30분 안에 돌아오고, 두고 온 녹음은 다른 탭·기기 끝내기로 바로 끝낼 수 있다. 조각 예약·완료도 생존으로 쳐서 신호만 실패한 경우를 견딘다. 증명 교체로 복제 탭 문제를 서버에서 막고, 시작 API의 재시도 판정을 그대로 둔다. 응답이 신호 응답과 같아 녹음 탭 처리가 하나로 모인다

## 결과

- 닫은 탭의 녹음이 최대 30분 진행 중으로 남고 그동안 회원의 새 녹음이 막힌다(다른 탭 끝내기로 해소)
- 끊긴 시간이 녹음 시간과 2시간 상한에 들어가 재생 길이보다 길 수 있다
- 연결 만료의 끝난 시각이 마지막 생존 시각이 되어 기다린 30분은 녹음 시간에 넣지 않는다
- Superseded 범위: ADR 695의 30초 만료와 끝난 시각 계산. 10초 신호 주기는 유지한다
- 이어 받은 뒤 이전 증명으로 온 신호·조각·일시정지·끝내기·이어 받기는 403 RECORDING_CONTROL_DENIED
- 같은 requestId 시작 재요청도 이전 증명이면 409 RECORDING_START_REQUEST_CONFLICT
- Superseded 범위: ADR 378의 시작 재요청 복구. 최초 탭 제어 증명과 다른 탭 조회·종료 규칙은 유지한다
- 이어 받기 때 확인되지 않은 예약 조각을 지우고 확인된 조각 바로 뒤로 다음 순번·프레임 위치를 되돌린다(사용자 결정 2026-10-28). 새로고침 사이 녹음하지 못한 구간은 음성에 없다

## 다시 논의해야 할 조건

- 두고 온 녹음이 새 녹음을 막는 불편이 반복될 때
- 30분 안에 돌아오지 못해 끝나는 녹음이 계속 나올 때
- 다른 탭·기기로 녹음 넘기기를 범위에 넣을 때
- 새로고침 전 미확인 예약 조각 처리 결정이 증명 교체와 부딪힐 때
