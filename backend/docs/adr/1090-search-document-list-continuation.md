# 탐색에서 첫 문서 목록의 순번을 유지한다

## 상태

Proposed

## 관련 Issue

[#1090 탐색 문서 목록 이어보기와 번호로 문서 열기](https://github.com/woowacourse-teams/2026-knot/issues/1090)

## 상황과 고려한 방식

대화에서 ‘더 보여줘’와 ‘3번 열어줘’는 사용자가 앞서 본 목록에 연결된다. 조회 조건과 커서만 보관한 뒤 문서를 다시 정렬하면 문서 추가·날짜 변경·삭제 후 같은 번호가 다른 문서를 가리킬 수 있다. 최초 조회의 문서 ID와 순번을 보관하면 별도 저장 공간이 필요하지만 이어보기와 이력에서 해당 번호를 유지할 수 있다.

## 결정

첫 조회의 범위·정렬·문서 ID 순서를 저장한다. 새 문서는 새 검색에서 확인한다. 목록과 답변별 표시 구간은 답변 완료와 같은 트랜잭션에서 저장한다.

목록에는 문서 제목을 보관하지 않는다. 이력과 SSE는 접근 가능한 현재 제목과 선택된 문서만 반환한다. 문서가 삭제되어도 해당 순번은 다른 문서에 재배정하지 않는다. 선택 카드와 실제 답변 근거는 서로 다른 필드로 표현한다.

## 결과

번호 참조와 멱등성은 PostgreSQL에서 검증한다. 목록 전체의 ID를 저장하므로 결과 수가 큰 경우의 저장량과 첫 응답 시간을 별도로 확인해야 한다.
