# 현재 Workspace의 생성 완료 DRAFT·ARCHIVED를 멤버 확인 여부와 무관하게 탐색하고 실제 답변 근거로 사용한다.

## 상태

Proposed

## 관련 Issue

- #670 [BE] 탐색 대상에 생성 완료된 DRAFT 문서 포함

## 한 줄 요약

현재 Workspace의 생성 완료 DRAFT·ARCHIVED를 멤버 확인 여부와 무관하게 탐색하고 실제 답변 근거로 사용한다.

## 왜 이 결정이 필요했나

문서 API는 생성 완료 즉시 DRAFT를 읽도록 허용하지만 기존 탐색 정책은 ARCHIVED로 제한한다.

동일 Workspace 멤버가 문서 화면에서 확인 가능한 DRAFT를 탐색 질문으로는 찾거나 답변 근거로 사용할 수 없다.

결정 동인:

- 생성 완료 즉시 탐색 가능
- 문서 읽기와 탐색의 동일한 Workspace 권한
- 보관 전환 중 연속성과 실제 근거 추적

## 트레이드 오프

- 기존 ARCHIVED만 탐색: 멤버 확인 후 사용하지만 생성 완료 문서도 확인 완료까지 검색되지 않는다.
- DRAFT와 ARCHIVED 모두 탐색: 즉시 사용하며 미확인 AI 생성 기록도 근거에 포함한다.

## 무엇을 결정했나

현재 Workspace의 생성 완료 DRAFT·ARCHIVED를 멤버 확인 여부와 무관하게 탐색하고 실제 답변 근거로 사용한다.

사용자가 기존 ARCHIVED 제한을 대체하고 확인 여부와 무관한 즉시 탐색 및 문서 읽기 권한 일치를 선택했다.

## 결과

- 개인 확인 상태가 탐색 가능 여부를 결정하지 않는다.
- 검색·목록·읽기·근거 저장에 같은 정책을 적용한다.
- 확인되지 않은 기록도 근거가 되며 확인·보관 상태를 자동으로 바꾸지 않는다.
- Transcript·생성 Job 범위 및 실제 근거 전체 보존·카드 3개는 유지한다.

## 다시 논의해야 할 조건

- 문서 편집·삭제나 개별 문서 접근 제한을 도입할 때
- DRAFT를 생성 완료 이외의 의미로 바꿀 때
- 멤버 확인을 답변 근거 허용 조건으로 바꾸는 제품 결정을 할 때
