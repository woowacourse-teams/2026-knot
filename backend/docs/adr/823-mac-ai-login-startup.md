# FileVault를 유지하고 최초 사용자 로그인 후 18766 AI·전용 터널·기존 Alloy를 사용자 LaunchAgent로 시작한다.

## 상태

Proposed

## 관련 Issue

- #823 [BE] 로그인 후 운영 AI와 전용 터널 자동 시작

## 한 줄 요약

FileVault를 유지하고 최초 사용자 로그인 후 18766 AI·전용 터널·기존 Alloy를 사용자 LaunchAgent로 시작한다.

## 왜 이 결정이 필요했나

운영 AI·전용 터널이 수동 프로세스로 실행되고 기존 수집기는 사용자 세션에 등록되어 있다.

재부팅으로 수동 프로세스가 사라지면 최초 로그인 후에도 실제 백엔드 전사 연결이 자동 복구되지 않는다.

결정 동인:

- FileVault 및 기존 권한 유지
- 최초 로그인 이후 자동 복구
- 18765·기존 수집·개발 작업 보존

## 트레이드 오프

- 사용자 LaunchAgent로 최초 로그인 뒤 시작: FileVault와 사용자 세션 유지, 로그인 전에는 기동하지 않음
- 로그인 전 완전 무인 복구: 별도 시스템 기동·보안 정책 검토가 필요해 이번 범위에서 제외

## 무엇을 결정했나

FileVault를 유지하고 최초 사용자 로그인 후 18766 AI·전용 터널·기존 Alloy를 사용자 LaunchAgent로 시작한다.

사용자가 최초 로그인 허용·FileVault 유지·화면 잠금 중 지속 실행을 운영 기준으로 명시했다.

## 결과

- 로그인 후 기동과 프로세스 종료 후 재시작을 관리한다.
- 로그인 전 기동은 완료 조건이 아니며 로그아웃·재부팅 실제 검증은 별도로 수행한다.

## 다시 논의해야 할 조건
