# 녹음 중 구간 전사를 영속 처리하고 종료 시 잔여 구간과 화자 증거를 병합한다.

## 상태

Proposed

## 관련 Issue

- #817 [BE] 녹음 중 구간 전사와 공정한 작업 처리 구현

## 한 줄 요약

녹음 중 구간 전사를 영속 처리하고 종료 시 잔여 구간과 화자 증거를 병합한다.

## 왜 이 결정이 필요했나

기존 PCM 저장·종료 흐름은 있지만 전사는 녹음 종료 후 전체 파일에 수행된다.

사용자는 다음 출시에서 종료 후 체감 대기를 줄이기 위해 녹음 중 처리를 핵심 과제로 지정했다.

결정 동인:

- 정상 두 녹음의 종료 후 30초 목표
- 기존 FE 계약 재사용
- 중단·재시도·삭제에도 내구성 유지

## 트레이드 오프

- 종료 후 최종 파일 하나를 일괄 전사: 기존 구현을 유지하지만 녹음 길이와 대기 작업의 영향을 받는다.
- 녹음 중 구간 전사: 종료 잔여 처리로 대기를 줄이지만 구간 상태·화자 정합·작업 배정이 필요하다.

## 무엇을 결정했나

녹음 중 구간 전사를 영속 처리하고 종료 시 잔여 구간과 화자 증거를 병합한다.

사용자가 녹음 중 전사를 선택하고 세부 설계를 위임했다. 저장과 전사 목표를 분리하고 검증되지 않은 품질·SLO는 출시 gate로 남긴다.

## 결과

- 종료 전에 처리한 결과를 내구 재사용할 수 있다.
- 입력/결과 버전과 소유권·cleanup 경합 및 전역 화자 연결 검증이 필요하다.
- 정상 30초 검증 실패나 품질 미달이면 활성화하지 않는다.

## 다시 논의해야 할 조건

- 실제 두 녹음·긴 기존 작업의 30초 목표 미달
- 검수된 화자 품질 저하
- 모델·동시성·FE 실시간 표시 요구 변경
