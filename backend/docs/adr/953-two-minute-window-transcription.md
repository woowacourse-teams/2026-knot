# 녹음 중 구간 전사를 새 음성 2분과 직전 10초로 바꾸고 보완·종료 후 재전사 없이 최종 전사로 쓴다.

## 상태

Proposed

## 관련 Issue

- #953 [BE] 녹음 중 구간 전사를 2분 구간과 이음매 정렬로 변경

## 한 줄 요약

녹음 중 구간 전사를 새 음성 2분과 직전 10초로 바꾸고 보완·종료 후 재전사 없이 최종 전사로 쓴다.

## 왜 이 결정이 필요했나

ADR 817은 30초 구간과 앞뒤 5초 문맥으로 녹음 중 전사를 정했고, 정확도는 사람 정답으로 측정하지 않았다.

2026-10-23~24 사람 정답 녹음 5개로 구간 길이·문맥·보완·모델을 비교했고, 30초 구간과 서버 병합의 정확도 손실을 확인했다.

결정 동인:

- 의미 오류(부정·숫자·동작·대상) 최소화
- 보지 않은 회의에서도 유지되는 정확도
- 녹음 중 처리로 종료 후 대기 축소

## 트레이드 오프

- 가) 3분 임시 전사 + 종료 후 전체 -mc 0 재전사: 녹음 52에서 가장 정확했지만 보지 않은 회의에서는 차이가 0.6%p였고 종료 후 대기가 길다
- 나) 2분 + 채우기·걸러내기·단어별 화자: 같은 자료에서는 좋아졌지만 보지 않은 회의에서 사전 기준 불통과
- 다) turbo 전체 한 번 전사: 2.4배 빠르지만 합산 11.9%로 2분 구간보다 낫지 않고 녹음 중 결과가 없다
- 라) 2분 구간을 보완 없이 최종본으로 사용: 채택

## 무엇을 결정했나

녹음 중 구간 전사를 새 음성 2분과 직전 10초로 바꾸고 보완·종료 후 재전사 없이 최종 전사로 쓴다.

2분 구간은 30초보다 정확하고, 보완은 일반화되지 않았으며, 전체 재전사와의 차이는 보지 않은 회의에서 작았다.

## 결과

- 구간 하나의 처리 시간이 늘어 마지막 구간 처리 시간이 종료 후 대기에 더해진다
- 조각 사고(긴 건너뛰기)는 재전사로 복구하지 않는다
- 정답 녹음 5개로 회귀를 확인할 수 있다
