# 기존 Qwen의 JSON 의도 분류를 첫 본문 delta 전에 검증하고 비검색 요청은 서버 고정 안내로 COMPLETED 종료한다.

## 상태

Proposed

## 관련 Issue

- #697 [BE] 탐색 답변 전 Qwen JSON 의도 분류와 범위 밖 요청 안내

## 한 줄 요약

기존 Qwen의 JSON 의도 분류를 첫 본문 delta 전에 검증하고 비검색 요청은 서버 고정 안내로 COMPLETED 종료한다.

## 왜 이 결정이 필요했나

Knot은 회의 기록 조회·요약·비교를 제공한다. 기존 도구 선택에서 범위 밖 요청의 자유 답변이 전송되는 문제가 있었다.

사용자가 케이크 만들기 등 일반 작업 응답을 지적했고 Qwen·D3-Flash 등 실제 모델의 속도·정확성을 비교한 뒤 기존 Qwen을 선택했다.

결정 동인:

- 회의 검색 오거절과 범위 밖 허용 최소화
- 기존 모델·HTTP·SSE 운영 기반 재사용
- 첫 본문 출력 전 서버 분기

## 트레이드 오프

- 기존 Qwen JSON 분류: 실험 정확도와 운영 재사용이 유리하나 호출 1회 지연 추가
- D3-Flash 별도 모델: 짧은 입력 분류가 빠르나 별도 운영과 제품 평가 필요
- 기존 첫 도구 선택: 호출 추가가 없으나 자유 답변과 재시도 오류 관측

## 무엇을 결정했나

기존 Qwen의 JSON 의도 분류를 첫 본문 delta 전에 검증하고 비검색 요청은 서버 고정 안내로 COMPLETED 종료한다.

실제 비교 실험과 사용자 선택에 따라 기존 Qwen을 먼저 적용한다. JSON을 엄격히 검증하고 자유 답변 우회를 제거한다.

## 결과

- 인사·안내·명확화·범위 밖은 서버 문구와 빈 근거로 완료
- 새 산출물과 검색+범위 밖 혼합 요청은 전체 거절
- 분류 장애는 FAILED, 검색 fallback과 자동 재시도 없음
- 중지·권한·기한·실행 token과 기존 전체 budget을 재사용
- 합성 평가 정확도는 실사용 보장이 아니며 정책 변경 평가를 분리

## 다시 논의해야 할 조건

- 실사용 오거절·범위 밖 허용이 제품 기준을 충족하지 못할 때
- 추가 지연·동시 처리 비용이 병목일 때
