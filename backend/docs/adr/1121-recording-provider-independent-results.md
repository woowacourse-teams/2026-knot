# 임시 CLOVA·Claude 공급자 전환과 영구 전사 공개·독립 요약·화자 표시명·참가자 수 계약을 분리한다.

## 상태

Proposed

## 관련 Issue

- #1121 [BE] 데모 공급자 전환과 전사 우선 공개·전체 요약·화자 설정 구현

## 한 줄 요약

임시 CLOVA·Claude 공급자 전환과 영구 전사 공개·독립 요약·화자 표시명·참가자 수 계약을 분리한다.

## 왜 이 결정이 필요했나

약 3분 발표를 기존 Knot 운영 서비스에서 빠르게 시연한다. 맥미니 전사·로컬 LLM 대신 CLOVA Speech와 Claude를 쓰고 녹음 종료 후 전체 전사한다.

현재 전사 조회와 전체 요약이 주제 분류에 묶여 분류 지연·실패 때 이미 저장한 전사를 보여 주지 못한다. 데모 공급자 교체와 별개로 전사·요약·표시명·참가자 수 기능은 계속 유지해야 한다.

결정 동인:

- 약 3분 데모의 종료 후 대기 감소
- 공급자 복귀와 영구 제품 기능의 독립
- 빈 전사·분류 실패·주제 0개 구분
- 사용자 입력의 제어권과 종료 확정값 보존

## 트레이드 오프

- 기존 Mac mini 전사·로컬 LLM 경로 유지: 기존 운영 연결을 유지하지만 사용자가 피하려는 데모 대기가 남는다.
- CLOVA Speech·Claude를 데모 설정으로 선택하고 영구 기능을 공통 계층에 구현: 외부 호출·비용·복구 제약이 추가되지만 빠른 시연과 기존 제공자 복귀를 함께 지원한다.

## 무엇을 결정했나

임시 CLOVA·Claude 공급자 전환과 영구 전사 공개·독립 요약·화자 표시명·참가자 수 계약을 분리한다.

데모 대기 시간을 줄이면서 기존 서비스 흐름을 유지한다. 전체 요약을 위해 주제나 문서를 억지로 만들지 않고, 공급자 복귀 후에도 사용자에게 유용한 제품 기능을 유지한다.

## 결과

- 외부 API 키·비용·응답 유실과 provider별 복구 제약을 관리해야 한다.
- 설정 복귀 후에도 전사 우선 보기·전체 요약·표시명·참가자 수를 유지한다.
- 분류와 요약을 독립해 빈 전사와 주제 0개를 구분한다.

## 다시 논의해야 할 조건

- 데모 종료 후 기존 제공자로 복귀할 때
- 실측 지연·정확도가 데모 목표에 못 미칠 때
- CLOVA의 결과 조회·복구 계약이 바뀔 때
