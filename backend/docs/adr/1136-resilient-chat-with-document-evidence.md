# 일반 대화와 필요한 기록 검색을 함께 제공하고 기술 오류는 제한 복구 뒤 안내 응답을 저장해 대화를 이어간다.

## 상태

Proposed

## 관련 Issue

- #1136 [BE] 일반 대화와 문서 근거 답변 및 기술 오류 안내 복구

## 한 줄 요약

일반 대화와 필요한 기록 검색을 함께 제공하고 기술 오류는 제한 복구 뒤 안내 응답을 저장해 대화를 이어간다.

## 왜 이 결정이 필요했나

ADR697의 비검색 고정 안내·기술 오류 FAILED 정책을 사용자 요구로 대체한다. 기존 ADR은 역사로 보존한다. 임시 클라우드 어댑터와 영구적인 제품 동작을 분리한다.

2026-11-12 dev에서 문서5개 검색 뒤 Claude가 JSON schema maxItems를 거절해 답변이 생성되지 않았다. 일반 질문도 분류 단계에서 차단됐다.

결정 동인:

- 데모 중 오류만으로 끝나는 대화 방지
- 일반 답변과 팀 기록 사실 구분
- 실제 출처·권한 보장
- 복구 지연과 API 비용 제한

## 트레이드 오프

- 호환성 오류만 수정: 작지만 일반 대화 차단과 실패 화면이 남는다.
- 일반 대화·필요한 기록 검색·제한 복구 후 안내: 선택. 검증과 표시 계약을 함께 바꾼다.
- 녹음 집중 모드: 범위를 제한할 수 있으나 새 UI와 모드가 필요하다.

## 무엇을 결정했나

일반 대화와 필요한 기록 검색을 함께 제공하고 기술 오류는 제한 복구 뒤 안내 응답을 저장해 대화를 이어간다.

사용자가 일반 챗봇과 기록 검색을 함께 원했고 오류 화면 대신 대화 지속을 선택했다. 팀 사실을 추측하지 않고 기술 장애와 저장 완료 의미를 분리한다.

## 결과

- 일반 질문과 문서0개도 모델 생성 경로를 사용한다.
- COMPLETED는 응답 또는 안내 저장 완료이며 질문 해결·근거 검증 성공이 아니다.
- 유한 복구·실제 출처 검증·기존 FAILED 표시와 회귀 검증이 필요하다.

## 다시 논의해야 할 조건

- 일반 지식과 팀 결정이 혼동되거나 팀 사실을 꾸며내는 사례
- 반복 측정에서 지연·품질·안내 비율이 데모 기준을 충족하지 못할 때
