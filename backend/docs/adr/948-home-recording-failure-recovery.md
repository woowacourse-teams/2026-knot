# 홈 실패를 복원하고 오디오의 일수 기반 보관·재시도 제한을 제거한다

## 상태

Proposed

## 관련 Issue

- #948 홈 녹음 실패·재시도와 오디오 보관 일수 제한 제거

## 결정

현재 Workspace·본인 녹음을 활성 녹음/일시정지 → 처리 중 → 실패 순으로 선택한다.
같은 우선순위는 시작 시각과 ID 내림차순이며 새 녹음 완료 뒤 이전 실패를 복원한다.
오디오 보관·자동 삭제와 전사 재시도에는 경과 일수 제한을 두지 않는다.

2026-10-24 최초 초안의 ‘30일 후에도 제목은 유지하되 재시도 불가’는 같은 날 사용자 정정으로 대체됐다.
사용자는 재시도 기간 검사와 오디오 보관·자동 삭제의 30일 제한을 함께 제거하도록 명시했다.

## 검토한 대안

- 기존 최신 한 건만 선택: 이전 실패가 숨겨져 사용자 요청과 맞지 않아 채택하지 않았다.
- 활성→처리 중→실패 순으로 복원: 사용자가 선택했다.
- 오디오 보관·재시도 30일 유지: 최초 초안에 있었으나 최신 사용자 정정으로 폐기했다.
- 재시도 기간 검사만 제거하고 오디오 자동 삭제는 유지: 확인 질문의 대안이며 선택하지 않았다.
- 보관·자동 삭제와 재시도 일수 제한을 함께 제거: 사용자가 선택했다. 날짜로 생기는 접수·처리 거절도 함께 제거해야 한다.

## 적용 범위

- current의 retryable, 전사 재접수·결과 채택, 오디오 저장 재시도, 최종화·입력 준비·구간 전사의 날짜 가드를 제거한다.
- 일수만 사유인 삭제 후보 선정을 중단한다. 과거 예약도 실행 전에 현재 유효한 정리 사유를 확인하며 일수 경과만 사유이면 실행하지 않는다.
- 사용 가능한 파일과 현재 상태·권한을 검증하고 실패 제목을 유지한다. 두 홈 실패 카드 안내는 ‘다시 시도할 수 있어요’로 표시한다.
- NO_CONTENT·폐기·탈퇴·Workspace 삭제, 최종 오디오 확정 뒤 불필요한 원시 청크 정리는 유지한다.
- 문서 실패 Job·입력은 마지막 실패 후 168시간 미만, 사용자 직접 재시도 3회 미만을 유지한다. 성공 문서와 연결 원문 보존도 유지한다.
- 과거 삭제 자료 복구, 로그인 refresh 만료, Presigned URL·작업 lease/timeout은 변경하지 않는다.

## 결과와 검증 경계

오래된 실패도 실제 파일을 사용할 수 있고 접수 조건을 충족하면 다시 시도할 수 있다.
일반 오디오는 날짜만으로 정리되지 않으며 명시적 정리 사유가 생길 때까지 저장 공간을 사용한다.
홈 GET만 바꾸면 기존 POST·worker·삭제 작업이 같은 오디오를 거절하거나 삭제하므로 공통 정책을 함께 정정한다.

[ADR 867](867-current-recording-processing-state.md)의 최신 한 건·실패 제외 범위는 이 결정으로 대체한다.
