# 홈 current는 활성→처리 중→실패 순으로 이전 실패를 복원하며 전사 실패 제목은 30일 뒤에도 재시도 불가 상태로 유지한다.

## 상태

Proposed

## 관련 Issue

- #948 [BE] 홈 녹음 실패 상태와 재시도 대상 조회

## 한 줄 요약

홈 current는 활성→처리 중→실패 순으로 이전 실패를 복원하며 전사 실패 제목은 30일 뒤에도 재시도 불가 상태로 유지한다.

## 왜 이 결정이 필요했나

기존 current의 최신 한 건·실패 제외 계약과 새 홈 실패·재시도 요구를 정합시키는 FE·BE 공통 상태 계약이다.

근거: [홈 요구사항 STT-R24](https://app.notion.com/p/3edb43517522819d83a6fa3dfcdc3115), [현재 녹음 API](https://app.notion.com/p/c45b43517522837aa1d081b71d43f645), [HOME-024-06](https://app.notion.com/p/3f2b435175228181abdef60f37c2e536), [HOME-024-03](https://app.notion.com/p/3f2b4351752281fab68dcfdef55099d8).

녹음이 전사 또는 문서 생성에 실패하면 기존 current가 204를 반환해 홈에서 실패와 가능한 재시도를 확인할 수 없고, 새 녹음 완료 뒤 이전 실패를 보여 줄 기준도 필요하다.

결정 동인:

- 메인에서 실패 단계와 재시도 가능 여부 확인
- 현재 Workspace·본인 한 건과 활성 작업 우선
- 입력 보관과 실패 제목 표시의 구분
- FE·BE가 반복 참조할 단일 계약

## 트레이드 오프

- 후보 선택: 기존처럼 최신 녹음 한 건만 먼저 선택하고 과거 실패를 복원하지 않는다. 단순하지만 새 녹음 완료 뒤 이전 실패는 숨겨진다.
- 후보 선택: 활성→처리 중→실패 우선순위로 고르고 이전 실패를 복원한다. 사용자가 선택했으며 후보 조회와 상태 조합이 필요하다.
- 전사 실패 표시: 업로드 완료 후 30일에 홈 후보에서도 제외한다. 보관·재시도 종료와 표시 종료가 일치한다.
- 전사 실패 표시: 30일 이후에도 제목을 유지하고 retryable=false로 제공한다. 사용자가 선택했으며 숨김 기능 없는 장기 표시를 감수한다.

## 무엇을 결정했나

홈 current는 활성→처리 중→실패 순으로 이전 실패를 복원하며 전사 실패 제목은 30일 뒤에도 재시도 불가 상태로 유지한다.

메인에서 실패 상황을 확인하고 가능한 재시도를 제공하려는 요청에 따라, 사용자는 새 녹음 완료 후 이전 실패 복원과 전사 보관 종료 뒤에도 실패 제목 유지를 직접 선택했다. 파일 보관·접수 가능 조건은 기존 제한을 유지한다.

## 결과

- 홈에서 이전 실패와 재시도 불가 상태를 확인할 수 있다.
- 단순 최신 한 건 조회 대신 우선순위 후보 조회와 실제 재시도 조건 집계가 필요하다.
- 전사 실패 제목은 장기간 남을 수 있으며 오디오·원문 보관이 함께 연장되지는 않는다.
- 기존 [ADR 867](867-current-recording-processing-state.md)의 최신 한 건·실패 제외 정책을 이 범위에서 대체한다. 새 ADR은 팀 승인 전 Proposed이며 원본 ADR의 상태는 변경하지 않는다.

## 다시 논의해야 할 조건

- 실패 숨김·해제나 실패 목록 요구가 생길 때
- 전사·문서 보관·재시도 정책이 바뀔 때
- 여러 사용자/여러 녹음 카드 또는 별도 일괄 접수 계약이 필요할 때
