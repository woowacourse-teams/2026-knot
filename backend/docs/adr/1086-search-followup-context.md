# 탐색 질문 조건을 저장하고 짧은 후속 질문은 검증된 단일 회의에서 다시 검색한다

## 상태

Proposed

## 관련 Issue

- #1086 [BE] 탐색 후속 질문에서 주제와 조건 이어가기

## 한 줄 요약

탐색 질문 조건을 저장하고 짧은 후속 질문은 검증된 단일 회의에서 다시 검색한다

## 왜 이 결정이 필요했나

기존 의도 분류와 답변 생성은 대화 본문을 읽는다. 워커의 검색기 호출에는 현재 질문이 전달된다.

짧은 후속 질문에서 회의와 주제가 생략되면 검색 범위가 넓어질 수 있다. 실패한 질문 조건과 검증된 회의 근거의 유효 시점이 다르다.

결정 동인:

- 회의 귀속과 현재 권한
- 동일 질문 중복 방지
- 실패 후 질문 조건 유지

## 트레이드 오프

- 이전 질문을 검색용 문자열로 재작성해 기존 검색기에 전달한다. 적용 범위가 작으나 회의 제한의 정확성을 문자열에 맡기게 된다.
- 질문 조건을 저장하고 검증된 인용이 가리키는 회의 ID를 조회 조건으로 전달한다. 저장 구조와 권한 재확인이 필요하다.

## 무엇을 결정했나

탐색 질문 조건을 저장하고 짧은 후속 질문은 검증된 단일 회의에서 다시 검색한다

회의 ID로 범위를 제한하면 다음 질문의 단어가 검색 범위를 바꾸지 않는다. 질문 조건은 질의 전에 저장하고 회의 ID는 완료 답변의 실제 인용에서 복원한다.

## 결과

- 질문 ID당 조건 한 행을 보관한다.
- 이전 인용이 모호하면 확인 질문을 기존 SSE로 보내고 현재 범위를 넓히지 않는다.
- 실제 공급자와 dev 첫 Delta p95는 따로 검증한다.

## 다시 논의해야 할 조건

- 확인 후보 선택이나 비교 답변 번호를 도입할 때
- dev에서 권한·지연·회귀 기준을 충족하지 못할 때
