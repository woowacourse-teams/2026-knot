# 탐색 이력의 현재 근거 접근과 당시 문서 버전

## 상태

Proposed

## 관련 Issue

[#1092 탐색 이력에서 근거 문서 접근과 변경 상태 구분](https://github.com/woowacourse-teams/2026-knot/issues/1092)

## 상황과 고려한 방식

탐색 이력과 SSE 재연결은 저장된 답변과 현재 조회되는 근거 카드를 보여준다. 기존 내부 조인은 삭제되거나 워크스페이스 범위를 벗어난 근거를 카드에서 제외한다. 그 경우에도 저장된 답변에 문서의 주장과 제목이 남을 수 있다. 화면에는 카드가 최대 세 개 표시되므로 답변이 실제 사용한 모든 근거를 별도로 확인해야 한다.

기존 방식으로 과거 본문을 유지하고 일부 카드만 제거하면 읽을 수 없는 자료가 답변을 통해 계속 보일 수 있다. 근거와 함께 과거 답변을 삭제하는 방식은 사용자의 탐색 이력을 지우며 수정과 접근 상실을 구분할 수 없다.

## 결정

- 답변이 실제 사용한 근거 중 하나라도 읽을 수 없으면 과거 본문과 카드 전체를 중립 안내로 대체한다. 대화 미리보기와 후속 질문 입력도 이 접근 판정을 사용한다. 전체 대화 접근권은 기존 인증과 멤버십 규칙으로 검사한다.
- 문서의 당시 ID와 현재 연결을 분리해 저장한다. 문서를 물리 삭제하면 현재 연결을 비우고 당시 ID와 근거 순위를 보존한다. 문서 목록과 번호 선택에는 해당 목록의 권한과 순번 규칙을 적용한다.
- 검색에서 확보한 원문의 제목·주제·본문 지문을 실제 사용 근거와 함께 저장한다. 현재 접근이 가능하면 내용 변경과 비교 불가를 안내한다. 과거 지문을 알 수 없는 데이터는 비교 불가로 표시한다.
- 과거 본문을 읽는 트랜잭션을 닫은 뒤 접근과 문서 버전을 확인한다. 버전 비교가 일시 실패하면 새 읽기 트랜잭션에서 한 번 더 시도하고 최신 접근 상태를 다시 확인한다.

## 영향

이력이나 SSE 재연결이 저장된 과거 답변을 변경하지 않는다. API의 본문·카드 필드를 쓰므로 화면은 기존 SSE 교체 이벤트로 표시를 갱신할 수 있다. 문서 전문의 지문을 계산하는 조회 비용은 운영 데이터와 부하에서 확인할 항목이다.
