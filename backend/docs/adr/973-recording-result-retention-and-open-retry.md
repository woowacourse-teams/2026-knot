# 녹음 처리 결과(전사 원문·실패 Job·NO_CONTENT 오디오)를 지우지 않고 전사·문서 생성·회의 전체 요약 재시도를 현재 멤버 누구나 횟수·기한 없이 하게 한다

## 상태

Proposed

## 관련 Issue

- #973 [BE] 녹음 처리 결과 삭제·재시도 제한 제거와 재시도 권한 확장

## 한 줄 요약

녹음 처리 결과(전사 원문·실패 Job·NO_CONTENT 오디오)를 지우지 않고 전사·문서 생성·회의 전체 요약 재시도를 현재 멤버 누구나 횟수·기한 없이 하게 한다

## 왜 이 결정이 필요했나

ADR 948은 오디오 30일 제한을 없앴지만 문서 실패 Job·입력의 168시간·사용자 3회, NO_CONTENT 정리, 시작한 Member 재시도를 유지했다. 홈 최근 녹음·녹음 문서 기능은 문서가 나오지 않은 녹음도 남기고 녹음 문서에서 그 자리 재시도를 요구한다.

팀원이 끝낸 녹음의 문서 생성이 실패하면 녹음 문서를 연 다른 멤버는 다시 시도할 수 없고, 7일이 지나거나 3회를 넘기면 시작한 Member도 다시 시도할 수 없으며, NO_CONTENT 녹음은 오디오가 삭제 예약된다.

결정 동인:

- 녹음 내역은 항상 남는다
- 녹음 문서를 여는 현재 멤버 누구나 그 자리에서 복구
- 접수 시 재검증과 중복 방지로 안전성 유지
- 폐기·탈퇴·Workspace 삭제 정리는 유지

## 트레이드 오프

- 현상 유지(ADR 948): 문서 실패 Job·입력 168시간, 사용자 재시도 3회, NO_CONTENT 오디오·원문 정리, 재시도는 시작한 Member만. 저장 공간은 줄지만 녹음 문서의 실패·NO_CONTENT 녹음을 남기거나 다시 시도할 수 없다
- 삭제와 횟수·기한 제한을 모두 없애고 현재 멤버 누구나 재시도(채택). 녹음 문서 요구를 만족하지만 보관량이 늘고 반복 재시도 비용 상한이 없다

## 무엇을 결정했나

녹음 처리 결과(전사 원문·실패 Job·NO_CONTENT 오디오)를 지우지 않고 전사·문서 생성·회의 전체 요약 재시도를 현재 멤버 누구나 횟수·기한 없이 하게 한다

사용자가 도메인 규칙 충돌 A5·A6에서 삭제하지 않음과 제한 제거, 멤버 누구나 재시도를 골랐고 문서·탐색 도메인 담당 흑곰이 삭제 정책 제거에 동의했다.

## 결과

- 실패·NO_CONTENT 녹음도 녹음 문서에서 언제든 복구할 수 있다
- 원문·오디오 보관량이 늘어난다
- 외부 STT·LLM 반복 호출 비용 상한이 없다
- [ADR 948](948-home-recording-failure-recovery.md)의 '문서 실패 Job·입력 168시간·사용자 3회 유지'와 'NO_CONTENT 정리 유지' 범위를 대체한다. 그 범위에서 948은 Superseded이며 948 파일은 수정하지 않는다

- 보관 기간에 관한 법·개인정보 요건이 확인될 때
