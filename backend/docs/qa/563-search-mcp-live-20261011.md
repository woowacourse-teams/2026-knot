# #563 실제 MCP·LLM 평가 — 2026-10-11

## 관측 범위

로컬 Spring Boot 앱의 실제 첫 질문 API·쿠키/CSRF·독립 Worker·내부 MCP HTTP·PostgreSQL·LLM 스트리밍·근거 metadata·SSE를 연결했다. 모델은 `llm-api.knoted.kr`의 `qwen3.8-27b`이며 공급자 호출을 mock하지 않았다. 운영 Workspace 데이터 대신 테스트 PostgreSQL에 합성 문서를 저장했다. 인증 토큰은 프로세스 환경으로만 전달했고 기록하지 않았다.

실행은 ignored `backend/build/manual-mcp-probe/init.gradle`과 `SearchMcpLiveProbeTest`를 사용했다. 결과 XML은 인수 테스트 2개, 실패·오류·skip 0, `BUILD SUCCESSFUL`이다. 일반 CI에는 외부 모델 호출을 넣지 않는다.

## 한계와 운영 전 확인

- 두 합성 사례 통과는 임의의 질문·많은 실사용 문서에서의 검색 완전성이나 모든 답변 문장의 근거 정합성을 보장하지 않는다.
- 종합 사례는 기본 120초 예산에 가깝다. 운영 질문으로 호출 횟수·문맥 크기·지연·실패율을 측정해야 한다.
- lexical 후보 검색이 의미만 유사한 표현을 놓칠 수 있다. 실패 사례를 모아 hybrid/vector 검색 도입 여부를 평가한다.
- 운영 DB의 migration 적용 이력·배포·ingress·프록시 SSE는 이번 평가 범위가 아니다.
- 재연결·명시적 중지·실패 재시도 endpoint는 후속 #567~#569 범위다.
